[[introduction]]
== Introduction

Spexflix Server is the backend of Spexflix, FGV's video service for the recordings of the spex.

The purpose of this documentation is to provide details on how to develop within Spexflix Server and how to integrate Spexflix Server into another application, e.g. a web application.
